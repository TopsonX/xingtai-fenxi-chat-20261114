# 24 种启动形态排查（Vue 3）

面向 A 股沪深市场的启动前夕形态研究站点：24 套独立模板逐一回测、逐一排查，并给出综合排序名单。数据截止 **2026-11-13 收盘**（Asia/Taipei，UTC+8）。今日为周日，不存在 11-14 / 11-15 的日线。

这是形态与公开数据研究，**不构成投资建议**。

## 本地运行

需要 Node.js 18+。

```bash
npm install
npm run dev
```

开发服务器默认 `http://127.0.0.1:5173/`。也可直接构建静态文件：

```bash
npm run build
npm run preview
```

构建产物在 `dist/`。已用相对路径（`base: './'`），可用任意静态服务器打开，例如：

```bash
python3 -m http.server 8080 --directory dist
```

不要直接用 `file://` 打开：页面通过 `fetch` 读取 `data/*.json`，本地文件协议可能被浏览器拦截。

## 页面结构

- `/` 目录：截止日、样本池、24 套形态的更贴/次贴/观察数量与一句话结论
- `/method` 方法与回测：模板如何定义（样例票与对齐相位）、怎么排查（无未来函数、前复权日线）、历史如何度量、局限
- `/p/T01` … `/p/T24` 各形态独立页：模板说明、排查与校准、历史归纳、当前分档名单、更贴/次贴（及部分观察）的四维解读与可拖动 Canvas K 线
- `/top50` 跨形态综合名单（方法下不够 50 不会凑数）

K 线为 Vue 3 + Canvas（可拖动、滚轮缩放），均线为 MA7 / MA45 / MA120 / MA200，黄虚线为 MA180。未使用 ECharts。

## 数据口径（摘要）

- 日线：扶摇前复权接口刷新，成交量由「股」换算为「手」。库内约 5459 只，其中 5213 只已到 2026-11-13，其余多为长期停牌或已退市，接口失败 0 只。
- 历史事件：规则首次触发、30 日冷却、20 日均成交额 ≥ 3000 万、股价 ≥ 2 元、非当前 ST。向前看 10/20/40 日 MFE、MAE 与收益。
- 「行情起点」= 40 日内 MFE≥25% 且第 40 日仍≥+10%；「几日游」= 短期冲高但第 40 日收益≤+2%。基准为全市场每 10 个交易日抽样。数字在本轮日线上重算，不是照抄 11-12 报告。
- 分层：更贴 / 次贴 / 观察。资金面不达标不抬级。综合名单以资金面为主、形态为入口，并倾向机构票。
- 主力净额来自新浪（超大单+大单，不等于真实机构）；龙虎榜只覆盖上榜日；财务为 2026 三季报；题材为东财 F10。缺项会在解读里写明，不编造。
