和报告同一套画法

不再用 ECharts 默认烛台。均线先在全部历史日线上算好再切片，K 线按报告里的方式画：影线用竖线，实体用柱子，红涨绿跌，缺口画成半透明色带。

放到你的 Vue 3 项目里

不用安装 ECharts。把页面里的 drawKline 拷进组件，数据字段是 { date, o, h, l, c, v, ma7, ma45, ma120, ma200, vma20 }。 均线一定要先对完整日线做均线，再截取展示窗口，否则 MA120 / MA200 会从半截才开始出现。 

onMounted(() => {
  drawKline(canvas, stock)
  new ResizeObserver(() => drawKline(canvas, stock)).observe(canvas)
})
