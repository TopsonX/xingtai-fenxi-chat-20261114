Vue 3 + ECharts K 线示例

配色和标注按前面那份跳空报告来：红涨绿跌、MA7 / 45 / 120 / 200、成交量，以及缺口色块。 黄色是深洗后仍未回补的跳空，红色是后来回补的高位衰竭跳空。可以拖动、缩放。

数据是前复权日线，截至 2026-11-06。华正新材 8 月 6 日缺口 119.31 → 122.00，视源股份 6 月 30 日缺口 32.19 → 32.36。

放到你的 Vue 3 项目里

npm i echarts 之后，把页面里的 buildOption 拷进组件，在 onMounted 里 echarts.init(el) 即可。 每根 K 线的字段是 { date, o, h, l, c, v }。也可以用 vue-echarts，把 option 绑到 <v-chart :option="option" autoresize />。 

import { ref, watch, onMounted, onBeforeUnmount } from 'vue'
import * as echarts from 'echarts'

const el = ref(null)
let chart
onMounted(() => {
  chart = echarts.init(el.value)
  chart.setOption(buildOption(stock))
})
watch(stock, (s) => chart.setOption(buildOption(s), { notMerge: true }))
onBeforeUnmount(() => chart?.dispose())
